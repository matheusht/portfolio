## Flagship project: RedThread

RedThread is a CLI-first autonomous AI red-teaming and defense-evidence engine for LLM and agentic systems.

**1-line:** CLI-first autonomous AI red-teaming and defense-evidence engine for LLM and agentic systems.

**What it does:**
- Runs adversarial campaigns with PAIR, TAP, Crescendo, and GS-MCTS
- Uses LangGraph-style supervisor/worker orchestration
- Scores traces with JudgeAgent/G-Eval-style rubrics, OWASP LLM and MITRE ATLAS categories, and regression gates
- Turns confirmed failures into scoped guardrail candidates, replay validation evidence, and agentic runtime checks for tool poisoning, confused deputy, canary containment, and resource amplification

**Recruiter-friendly:** Hands-on proof that I can build real AI security tooling, not just talk about risks. It automates LLM red teaming, evaluates jailbreak/prompt-injection failures, and produces evidence developers can use to harden AI systems.

**CTO-friendly:** Treats AI security like an engineering control loop: generate attacks, execute them in parallel, score behavior, synthesize candidate defenses, replay evidence, and track runtime risk for agent/tool workflows.

**Status:** Active research and engineering project (Phase 7 + Phase 8 hardening). Useful for local campaigns, replay evidence, deterministic agentic-security checks, and operator review.
