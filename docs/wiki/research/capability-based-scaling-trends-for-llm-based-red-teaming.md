# Capability-Based Scaling Trends for LLM-Based Red-Teaming

## Research Overview

This paper (ICLR 2026) establishes that Attack Success Rate (ASR) scales linearly with general model capability across 600+ attacker-target combinations. It provides a scaling-law framework to predict when human red teaming will become ineffective against increasingly capable models.

## Key Contributions

- Demonstrates a log-linear relationship between model capability and ASR across a large-scale benchmark
- Forecasts the crossover point where automated LLM red teaming surpasses human-driven red teaming effectiveness
- Provides a capability-based scaling framework that generalizes across diverse attack and target model pairs
- Validates findings across multiple model families and sizes, establishing predictive reliability

## Relevance to AI Security

This work directly informs when organizations should transition from human-led to automated red teaming pipelines. The scaling trends provide an empirical basis for allocating defensive resources and anticipating future attack surface expansion as general capability increases.
