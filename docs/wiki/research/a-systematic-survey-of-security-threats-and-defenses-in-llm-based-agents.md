# A Systematic Survey of Security Threats and Defenses in LLM-Based AI Agents: A Layered Attack Surface Framework

## Research Overview

This survey proposes a structured 7-layer attack surface framework (L1-L7) for analyzing security threats in LLM-based AI agents, covering everything from raw input processing to multi-agent ecosystem interactions. It systematically maps known attacks and defenses to each layer, accepted at a major venue.

## Key Contributions

- 7-layer attack surface taxonomy: Input (L1), Prompt (L2), Model (L3), Tool (L4), Memory (L5), Orchestration (L6), Ecosystem (L7)
- Systematic mapping of existing attacks (prompt injection, jailbreaks, tool misuse, memory poisoning) to specific layers
- Comprehensive defense catalog organized by layer coverage and mitigation strategy
- Identifies under-explored attack vectors at orchestration and ecosystem layers
- Accepted publication at a major academic venue

## Relevance to AI Security

This layered framework is essential reference architecture for any agentic security program. It provides the shared vocabulary for categorizing attack surface coverage across red team operations, and the layer mappings directly inform defense prioritization and tool placement.
