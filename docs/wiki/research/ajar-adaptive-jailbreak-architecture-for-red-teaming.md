# AJAR: Adaptive Jailbreak Architecture for Red-teaming

## Research Overview

AJAR bridges adaptive jailbreak algorithms with agent-native evaluation systems by exposing attack logic as Model Context Protocol (MCP) services. It provides a modular architecture that demonstrably improves upon PyRIT's Crescendo implementation for structured red teaming workflows.

## Key Contributions

- Defines a modular architecture that decouples jailbreak strategy from evaluation infrastructure via MCP
- Improves on PyRIT's Crescendo implementation with adaptive strategy selection
- Enables agent-native communication between red teaming components
- Provides a reusable service-oriented framework for composing attack algorithms

## Relevance to AI Security

AJAR's MCP-based approach aligns with the trend toward composable, protocol-driven security tooling. It enables standardized integration of jailbreak algorithms into evaluation pipelines and sets a foundation for interoperable red teaming infrastructure.
