# GS-MCTS (Group-aware Strategy-guided Monte Carlo Tree Search)

## Definition

GS-MCTS is a highly advanced multi-turn adversarial search framework that models a dialogue as a sequential decision-making game between two players: the Attacker and the Target LLM. It applies Monte Carlo Tree Search (MCTS) to explore the conversational space, using strategy priors and semantic clustering to handle the infinite branching factor of natural language.

```text
                     [Dialogue State s0]
                             |
                     (Select Strategy A)
                             ▼
                     [Dialogue State s1]
                     /       |       \
               Prompt v1  Prompt v2  Prompt v3 (Semantic Clustering)
                   |         |         |
                Score 2   Score 8   Score 5
```

## Why It Matters

- **Strategic Planning:** Unlike short-sighted heuristics, GS-MCTS plans multiple moves ahead, mapping out complex privilege escalation or social-engineering paths.
- **Language Branching Reduction:** Handles natural language's infinite branching factor by abstracting specific prompt generations into high-level *Strategy Priors* before text synthesis.
- **Robust Evaluation:** Employs rollouts and simulated dialogues to backpropagate potential future rewards back to current nodes.

## The Mathematical Framework

The core of GS-MCTS relies on the **Upper Confidence Bound applied to Trees (UCT)** formula to select the next action (or strategy) to evaluate:

$$UCT(s,a) = Q(s,a) + C \cdot P(s,a) \cdot \frac{\sqrt{N(s)}}{1 + n(s,a)}$$

Where:
- $Q(s,a)$: The action-value estimate (average score received when choosing action $a$ in state $s$).
- $N(s)$: The total number of times parent state $s$ has been visited.
- $n(s,a)$: The number of times action $a$ has been selected from state $s$.
- $P(s,a)$: The **Strategy Prior** — a probability distribution generated by a policy model indicating the baseline likelihood of strategy $a$ working in state $s$.
- $C$: An exploration constant that controls the trade-off between exploitation (high $Q$) and exploration (low visit count).

## The Four MCTS Phases

1. **Selection:** Starting at the root node, the engine traverses the tree by choosing actions that maximize the UCT formula until an unexpanded node is reached.
2. **Expansion:** The engine generates potential natural language realizations of the selected strategy. It groups them using **Group-aware Semantic Clustering** to ensure semantic diversity (avoiding generating 5 variations of the exact same phrasing).
3. **Simulation (Rollout):** The engine plays out a quick multi-turn simulated conversation between a lightweight Attacker and the Target model to estimate the terminal payoff.
4. **Backpropagation:** The terminal score ($1..10$) is propagated back up the ancestral nodes, updating $Q(s,a)$ values and visit counts $n(s,a)$.
